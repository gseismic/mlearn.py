# PLAN-019 实施结果：修复二分类指标标签与概率语义

## 实施内容

1. precision、recall 和 F1 增加 `pos_label=1` 参数。
2. TP、FP 和 FN 改为基于 `pos_label` 的 one-vs-rest 统计。
3. `log_loss` 增加 `pos_label=1` 并先编码真实标签。
4. `log_loss` 校验二分类类别数、正类存在性、数值概率、有限性和 `[0,1]` 范围。
5. 合法概率校验后继续裁剪，避免 `log(0)`。
6. 新增字符串标签、`{1,2}` 标签和非法概率测试。

## Review 结果

1. 默认 `0/1` precision、recall 和 F1 结果保持不变。
2. `{1,2}` 标签下假阳性正确计入非正类样本。
3. 字符串正类可通过 `pos_label` 明确指定。
4. 任意二分类标签对数损失与手工二元交叉熵一致。
5. 单类别缺少指定正类、多类别、NaN 和越界概率均明确失败。
6. 概率范围校验发生在数值裁剪之前。
7. 未发现需要追加修复的问题。

## 验证结果

- 指标和 GBDT 分类目标测试：`17 passed`
- 默认 `0/1` 指标：precision/recall/F1 均为 `0.5`
- `{1,2}` 默认正类 1：
  - precision：`0.5`
  - recall：`1.0`
  - F1：`0.6666666666666666`
- `python -m pytest -q`
  - 结果：`80 passed`
- 系统 `pytest -q`
  - 结果：`78 passed, 2 skipped`
