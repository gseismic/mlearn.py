# PLAN-018：修复线性模型预测与评分一致性

## 问题

NumPy 线性回归 `predict` 直接访问 `X.shape`，列表输入失败；不检查拟合状态和特征数。
`score` 自行计算 R²，常量目标时除零，完美预测也返回 `-inf`。PyTorch 后端复制了同一
评分公式，两个后端输入行为不一致。

## 目标

1. NumPy 和 PyTorch 后端使用统一特征、目标校验。
2. 预测支持列表和一维单样本。
3. 预测前检查拟合状态和训练特征数。
4. `score` 复用公共 `r2_score`。
5. 常量目标完美预测返回 1，非完美预测返回 0。
6. 无截距重训时 `intercept_` 保持 `None`。

## 实施步骤

1. NumPy 后端 `fit` 使用共享 `validate_X_y` 并保存特征数。
2. NumPy 后端 `predict` 使用共享 `validate_X`。
3. PyTorch 后端接入相同校验并保存特征数。
4. 两个后端 `score` 统一调用 `r2_score`。
5. 增加列表预测、单样本、常量目标、未拟合和错误特征数测试。

## 验证

1. `predict([[2.0]])` 和 `predict(np.array([2.0]))` 均返回 `(1,)`。
2. 常量目标完美拟合评分为 1。
3. 未训练和错误特征数预测明确失败。
4. 有 PyTorch 环境验证两个后端行为一致。
5. 运行目标测试和全量测试。

## Review 检查点

1. NumPy 设计矩阵是否在校验后才添加截距列。
2. PyTorch 输入是否仍转换为 float tensor。
3. `score` 是否不再包含重复 R² 公式。
