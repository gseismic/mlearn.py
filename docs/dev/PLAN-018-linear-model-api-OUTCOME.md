# PLAN-018 实施结果：修复线性模型预测与评分一致性

## 实施内容

1. NumPy 和 PyTorch 后端接入共享特征、目标校验。
2. 两个后端保存训练特征数并在预测时检查。
3. 预测支持列表和一维单样本输入。
4. 未训练模型预测明确抛出 `ValueError`。
5. 两个后端 `score` 统一调用公共 `r2_score`。
6. NumPy 无截距训练明确将 `intercept_` 设为 `None`。
7. 常量目标 R² 使用 `np.isclose` 处理浮点残差。
8. 新增预测输入、拟合状态、常量目标和无截距测试。

## Review 结果

1. 设计矩阵在输入校验后才添加截距列。
2. PyTorch 输入仍统一转换为 float tensor。
3. 两个后端已删除重复 R² 公式。
4. NumPy 常量拟合 SSE 约为 `2.5e-31`，PyTorch 约为 `9.2e-10`，均按数值完美预测处理。
5. 明显错误的常量预测仍返回 R² `0`。
6. 未发现需要追加修复的问题。

## 验证结果

- 线性模型和指标目标测试：`14 passed`
- 列表和一维单样本预测形状：`(1,)`
- 常量目标：
  - 数值完美预测：`1.0`
  - 明显错误预测：`0.0`
- `python -m pytest -q`
  - 结果：`75 passed`
- 系统 `pytest -q`
  - 结果：`73 passed, 2 skipped`

## 与计划差异

Review 阶段发现公共 `r2_score` 使用严格零比较，因此追加数值容差修复和对应指标测试。
