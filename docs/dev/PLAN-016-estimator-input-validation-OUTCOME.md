# PLAN-016 实施结果：统一树与集成模型输入校验

## 实施内容

1. 新增共享 `validate_X`、`validate_y` 和 `validate_X_y`。
2. 训练特征统一校验为非空二维有限实数矩阵。
3. 一维或单列目标统一转换为一维。
4. 回归目标统一转换为有限浮点数组。
5. 分类树、回归树、随机森林和 GBDT 全部接入共享校验。
6. 预测支持一维单样本，并检查拟合状态和特征数量。
7. GBDT 回归内部预测和残差状态统一为一维浮点数组。
8. 新增空数据、样本数不一致、列目标、单样本预测和非有限特征测试。

## Review 结果

1. 所有模型在 bootstrap 或树分裂前完成 X/y 样本数检查。
2. GBDT 回归列目标不再产生二维广播。
3. 字符串分类标签不受回归数值校验影响。
4. 预测在树遍历前检查模型状态和训练特征数。
5. NaN 特征在阈值排序前明确拒绝。
6. Review 发现两个历史测试仍依赖随机初始化：
   - PyTorch 测试增加固定 `torch.manual_seed(0)`
   - 随机森林基础测试改用本地固定数据 RNG 和模型种子
7. 固定随机性后调整回归森林测试深度，使性能断言保持严格且稳定。

## 验证结果

- 输入校验及树、集成目标测试：`50 passed`
- 原失败反例：
  - GBDT 列目标预测形状：`(5,)`
  - 回归树单样本预测形状：`(1,)`
  - 样本数不一致：明确 `ValueError`
  - 预测特征数不一致：明确 `ValueError`
- `python -m pytest -q` 连续运行三次：
  - 每次均为 `59 passed`
- 系统 `pytest -q`：
  - `58 passed, 1 skipped`

## 与计划差异

Review 阶段额外修复了历史测试中的随机性，使全量测试能够稳定重复，而不是偶然通过。
