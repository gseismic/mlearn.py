# PLAN-004 实施结果：修复指标输入形状与类型一致性

## 实施内容

1. 新增 `ensure_1d_array`，将一维、行向量和列向量规范为一维数组。
2. 新增 `ensure_matching_1d_arrays`，统一检查空输入和成对长度。
3. 分类指标、回归指标和对数损失全部在计算前调用统一校验。
4. `log_loss` 现在支持列表和元组输入。
5. 新增广播反例、列表输入和非法形状测试。

## Review 结果

1. 仅行向量或列向量会被压平，普通二维矩阵会明确拒绝。
2. 所有指标在比较或算术运算前完成形状检查。
3. 分类和回归指标采用相同输入规则。
4. `f1_score` 与其子指标存在轻量重复校验，但保留了各公开函数独立安全性。
5. 未发现需要追加修复的问题。
