# PLAN-008：修复回归树 `min_impurity_decrease` 语义

## 问题

当前实现将节点原始 SSE 减少量直接与 `min_impurity_decrease` 比较。完全复制同一个数据集
会按复制倍数放大 SSE，因此在数据分布完全相同的情况下改变是否分裂的结果。

## 目标

1. 使用根样本数加权的不纯度下降判断停止条件。
2. 完全复制数据集不改变分裂决策。
3. 保留 `_best_split` 的原始 SSE 优化目标。
4. 与标准 CART 的 `min_impurity_decrease` 尺度一致。

## 实施步骤

1. 在 `_grow_tree` 中将最佳分裂 SSE 减少量除以根训练样本数。
2. 使用归一化下降量与 `min_impurity_decrease` 比较。
3. 增加不同复制倍数下分裂决策一致的测试。
4. 验证阈值上下两侧都具有一致行为。

## 验证

1. 原始两样本数据及其 2 倍、10 倍复制在同一阈值下均分裂。
2. 更高阈值下上述数据均不分裂。
3. 运行目标测试和全量测试。

## Review 检查点

1. 分母是否始终为根训练样本数。
2. `_best_split` 的候选排序是否保持不变。
3. 特征重要性使用的 SSE 是否未被错误归一化两次。
