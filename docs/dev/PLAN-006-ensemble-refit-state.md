# PLAN-006：修复集成模型重复训练状态

## 问题

随机森林和两种 GBDT 的基学习器列表只在构造函数中初始化。对同一对象再次调用 `fit`
会继续追加树，导致实际树数量超过 `n_estimators`，新训练结果混入旧模型。

## 目标

1. 每次 `fit` 默认重新训练模型。
2. 训练完成后的基学习器数量始终等于 `n_estimators`。
3. 四个集成模型行为一致。
4. 不引入未声明的增量训练语义。

## 实施步骤

1. 在随机森林分类器和回归器的 `fit` 开始处清空 `trees`。
2. 在 GBDT 分类器的 `fit` 开始处清空 `trees`。
3. 在 GBDT 回归器的 `fit` 开始处清空 `trees_`。
4. 为四个模型增加重复训练树数量测试。

## 验证

1. 首次和第二次训练后树数量均等于 `n_estimators`。
2. 重训后预测只由本轮基学习器构成。
3. 运行四类集成模型目标测试和全量测试。

## Review 检查点

1. 清空动作是否发生在训练循环前。
2. 是否遗漏任何保存基学习器的集合。
3. 是否意外改变单次训练算法。
