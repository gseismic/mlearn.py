# PLAN-003：修复回归树特征重要性

## 问题

当前实现将每个叶节点均值当作一个训练样本，再根据叶均值计算方差下降。该方法丢失叶节点
样本数和节点内残差，可能把最重要特征排序错误；无分裂树还会因归一化除零返回 `NaN`。

## 目标

1. 使用训练节点的真实样本数和平方误差计算不纯度下降。
2. 标准特征重要性累计样本加权方差下降，即节点 SSE 减少量。
3. 保留不加权局部方差下降的可选行为。
4. 无分裂树返回有限的全零重要性。
5. 剪枝后的树仍具备计算重要性所需统计量。

## 实施步骤

1. 为所有回归树节点保存 `n_samples` 和 `squared_error`。
2. 使用节点统计量计算父节点与子节点的方差下降。
3. `weighted=True` 累计 SSE 减少量，作为默认标准行为。
4. 删除基于叶均值重建节点值的逻辑。
5. 归一化前检查重要性总量。
6. 增加标准排序反例和无分裂树测试。

## 验证

1. 已知主特征数据集的重要性排序正确。
2. 与 scikit-learn 在固定数据上的标准特征重要性结果比较。
3. 常量特征树返回零数组。
4. 运行目标测试和全量测试。

## Review 检查点

1. SSE 是否基于节点原始目标值计算。
2. 加权方差下降是否等价于父 SSE 减左右子 SSE。
3. 剪枝叶节点是否保存完整统计量。
