# PLAN-004：修复指标输入形状与类型一致性

## 问题

当 `y_true` 为 `(n, 1)`、`y_pred` 为 `(n,)` 时，NumPy 会将两者广播为 `(n, n)`，
指标函数不会报错却返回错误数值。`log_loss` 还没有调用数组转换函数，列表输入会触发类型
异常。

## 目标

1. 所有指标统一接受一维向量、列向量和行向量。
2. 向量输入统一规范为 `(n,)` 后再计算。
3. 拒绝普通二维矩阵、空数组和长度不一致输入。
4. `log_loss` 支持列表和元组。
5. 保持已有合法一维输入结果。

## 实施步骤

1. 在 `metrics.utils` 新增单向量规范化和成对向量校验函数。
2. 所有分类、误差和评分指标统一调用成对校验。
3. 删除 `r2_score` 中重复的长度检查。
4. 增加列向量广播反例、列表 `log_loss` 和非法形状测试。

## 验证

1. 列向量与一维向量的完美预测得到 MSE `0`、R² `1`。
2. 列表输入的二元对数损失得到正确有限值。
3. 长度不一致和二维矩阵明确抛出 `ValueError`。
4. 运行目标测试和全量测试。

## Review 检查点

1. 规范化是否只压平行向量或列向量。
2. 是否在任何算术运算前检查形状。
3. 分类指标是否与回归指标使用同一规则。
