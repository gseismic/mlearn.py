# PLAN-010：修复 GBDT 分类算法与标签处理

## 问题

当前分类 GBDT 直接假设标签为 `0/1`，单类别会产生无穷初始 log-odds，其他标签会产生
无效概率。基学习器只拟合 `y-p` 后直接把回归树均值加入 raw score，没有执行逻辑损失下
标准的 Newton 叶节点更新，收敛速度和概率质量明显偏差。

## 目标

1. 明确实现二分类逻辑损失 GBDT。
2. 支持任意两种可排序标签并在预测时恢复原标签。
3. 单类别和多类别输入明确抛出 `ValueError`。
4. 每棵树叶节点按一阶梯度和二阶 Hessian 执行 Newton 更新。
5. 概率计算在极端 raw score 下保持有限并归一化。

## 实施步骤

1. 使用 `np.unique(..., return_inverse=True)` 建立二分类标签编码。
2. 以类别 1 比例的 log-odds 初始化 raw score。
3. 每轮计算概率、负梯度和 Hessian。
4. 回归树拟合负梯度后，递归更新每个叶节点输出：
   `sum(y-p) / sum(p(1-p))`。
5. 使用稳定 sigmoid 生成概率。
6. `predict` 将二元预测映射回 `classes_`。
7. 增加标签、概率、损失和非法类别数测试。

## 验证

1. 字符串二分类标签训练和预测正常。
2. 概率均为有限值，每行和为 1。
3. 训练对数损失低于仅使用初始常数预测的损失。
4. 单类别和三类别数据明确失败。
5. 与参考实现比较训练损失处于合理范围。

## Review 检查点

1. 叶节点 Newton 分母是否使用同一轮预测的 Hessian。
2. 每个训练样本是否只进入一个叶节点更新。
3. `predict_proba` 列顺序是否与 `classes_` 一致。
