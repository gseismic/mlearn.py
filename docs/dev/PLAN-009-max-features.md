# PLAN-009：修复 `max_features` 解析与重训行为

## 问题

随机森林将 `sqrt`、`log2` 和浮点比例原地改写为整数。单特征 `log2` 和较小比例可能得到
零，分类树异常、回归树静默退化；树首次训练还会把 `None` 改写为旧特征数，换维度重训
时可能抽取超过当前特征数的列。

## 目标

1. 所有树模型使用一致的 `max_features` 解析规则。
2. 解析结果始终位于 `[1, n_features]`。
3. 用户构造参数不在训练过程中被改写。
4. 每次 `fit` 根据当前数据重新计算 `max_features_`。
5. 非法字符串、整数和比例明确抛出 `ValueError`。

## 实施步骤

1. 新增共享 `resolve_max_features`。
2. 分类树和回归树增加训练态字段 `max_features_`。
3. 随机森林使用共享解析器并将解析值传给子树。
4. `_best_split` 根据实际传入特征子矩阵列数遍历。
5. 增加单特征 `log2`、小比例、非法值和换维度重训测试。

## 验证

1. 单特征 `log2` 和小比例均解析为 1。
2. `None` 或字符串配置在不同维度重训时重新解析。
3. 配置字段保持原始值，训练态字段反映当前解析结果。
4. 运行树和随机森林目标测试及全量测试。

## Review 检查点

1. 是否仍有代码原地修改 `self.max_features`。
2. 所有抽样数量是否使用 `max_features_`。
3. 浮点比例 `1.0` 是否表示全部特征。
