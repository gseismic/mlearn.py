# PLAN-007 实施结果：修复回归树代价复杂度剪枝

## 实施内容

1. 子树经验风险改为所有叶节点 SSE 之和除以根样本数。
2. 复杂度项改为 `ccp_alpha * 叶节点数量`。
3. 单叶代价使用当前节点 SSE 和一个叶节点复杂度。
4. 新增叶节点 SSE 汇总和叶节点计数辅助函数。
5. 删除旧的批量预测和平均 MSE 剪枝辅助代码。
6. 增加明确剪枝阈值的回归测试。

## Review 结果

1. 子树风险由叶节点风险相加得到，适合自底向上局部比较。
2. 所有误差项统一除以根样本数，`ccp_alpha` 使用全局平均误差尺度。
3. 复杂度只使用叶节点数，不再把内部节点重复计入。
4. 剪枝后的叶节点保留均值、样本数和 SSE。
5. 仓库内不存在旧剪枝辅助函数的剩余调用。
6. 未发现需要追加修复的问题。

## 验证结果

- `python -m pytest tests/tree/test_tree_regressor.py -q`
  - 结果：`4 passed`
- 明确边界：
  - `ccp_alpha < 25`：保留两叶树，训练 MSE 为 `0`
  - `ccp_alpha >= 25`：剪为单叶，训练 MSE 为 `25`
- `python -m pytest -q`
  - 结果：`28 passed`

## 与计划差异

Review 阶段确认旧 `_predict_tree_batch` 和 `_calculate_error` 已无调用，因此一并删除。
