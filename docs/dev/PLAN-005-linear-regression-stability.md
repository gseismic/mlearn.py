# PLAN-005：修复线性回归数值稳定性

## 问题

NumPy 线性回归通过显式计算 `(XᵀX)⁻¹Xᵀy` 求解。共线特征、重复特征、特征数
大于样本数时 `XᵀX` 可能奇异并抛出 `LinAlgError`；即使可逆，该方法也会平方条件数，
降低数值稳定性。

## 目标

1. 秩亏和欠定数据能够得到最小二乘预测。
2. 避免构造和求逆 `XᵀX`。
3. 保持 `coef_`、`intercept_` 和 `predict` 的现有形状。
4. 明确拒绝不支持的输入维度和多输出目标。

## 实施步骤

1. 将输入规范为 NumPy 数组并校验 `X`、`y` 维度和样本数。
2. 将单列目标规范为一维向量。
3. 使用 `np.linalg.lstsq(..., rcond=None)` 求最小二乘解。
4. 增加完全共线特征和欠定数据测试。

## 验证

1. 旧反例不再抛出 `Singular matrix`。
2. 秩亏训练数据预测与目标一致。
3. 参数与直接调用 `np.linalg.lstsq` 的结果一致。
4. 运行目标测试和全量测试。

## Review 检查点

1. 截距列是否只在 `fit_intercept=True` 时添加。
2. 目标列向量是否只压平单列，不接受多输出目标。
3. 返回参数形状是否保持兼容。
