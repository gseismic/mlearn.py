# PLAN-001：分类树支持任意类别标签

## 问题

`DecisionTreeClassifier` 将原始标签直接作为类别计数数组的下标，因此只支持从 `0`
开始的连续整数。非连续整数会触发 `IndexError`，字符串标签会触发 `TypeError`。

## 目标

1. 支持整数、字符串等可由 NumPy 排序和去重的类别标签。
2. 树内部继续使用紧凑整数编码，避免修改基尼系数计算方式。
3. `predict` 返回训练时的原始标签。
4. 不改变现有 `0/1` 标签数据集的行为。

## 实施步骤

1. 在 `fit` 中通过 `np.unique(..., return_inverse=True)` 建立 `classes_` 和内部标签。
2. 使用内部连续标签训练和剪枝。
3. 将单样本树预测明确为类别索引，并在公开 `predict` 中映射为原标签。
4. 增加非连续整数标签和字符串标签测试。

## 验证

1. 新增测试必须验证训练集预测与原标签完全一致。
2. 运行分类树测试。
3. 运行全量测试，确认现有行为没有回归。

## Review 检查点

1. 树中所有类别计数是否只接收连续内部标签。
2. 剪枝后的叶节点是否仍保存内部标签。
3. 返回数组的标签 dtype 是否与 `classes_` 映射一致。
