# PLAN-017：统一估计器超参数校验

## 问题

`n_estimators=0` 会让分类森林返回空预测、回归森林返回 `NaN`。树深度、最小分裂样本数、
剪枝系数、不纯度阈值和 GBDT 学习率也没有边界校验，非法值可能静默生成退化模型。

## 目标

1. 基学习器数量必须是正整数。
2. 树最大深度必须为 `None` 或正整数。
3. `min_samples_split` 必须是不小于 2 的整数。
4. `ccp_alpha` 和 `min_impurity_decrease` 必须是有限非负实数。
5. GBDT `learning_rate` 必须是有限正实数。
6. 布尔值不能冒充整数或实数参数。
7. 校验在 `fit` 执行，覆盖训练前参数修改。

## 实施步骤

1. 新增共享正整数、正实数和非负实数校验函数。
2. 分类树和回归树在 `fit` 校验树参数。
3. 两种随机森林在 `fit` 校验森林和树参数。
4. 两种 GBDT 在 `fit` 校验迭代数、学习率和树参数。
5. 增加零树、非法深度、分裂样本数、剪枝参数和学习率测试。

## 验证

1. 四种集成模型拒绝 `n_estimators=0`。
2. 树拒绝零深度、过小分裂样本数和负复杂度参数。
3. GBDT 拒绝零学习率。
4. 合法边界配置继续训练。
5. 运行目标测试和全量测试。

## Review 检查点

1. `bool` 是否在数值分支前明确拒绝。
2. NumPy 整数和浮点标量是否正常支持。
3. 是否所有使用相关参数的模型都调用校验。
