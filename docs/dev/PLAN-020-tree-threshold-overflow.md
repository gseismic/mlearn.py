# PLAN-020：修复树分裂阈值数值溢出

## 问题

分类树和回归树使用 `(left + right) / 2` 计算相邻特征值中点。接近 `int64` 上限时加法
溢出为负数，生成空子节点；分类树随后崩溃，回归树可能反复选择同一无效分裂直至递归
溢出。同号极大浮点数也存在加法溢出风险。

## 目标

1. 中点计算不执行两端值直接相加。
2. 支持接近整数和浮点类型极限的有限特征值。
3. 浮点精度无法表示严格中点时仍生成非空分裂。
4. 分类树和回归树使用同一阈值函数。
5. 普通数值数据分裂行为保持不变。

## 实施步骤

1. 在树共享工具中新增 `split_threshold(left, right)`。
2. 使用 `float(left)/2 + float(right)/2` 计算安全中点。
3. 中点不是有限值或没有严格位于两端之间时，使用右端点作为阈值。
4. 分类树和回归树统一调用共享函数。
5. 增加接近 `int64` 上限和极大浮点值测试。

## 验证

1. 接近 `int64` 上限的分类树完全拟合训练标签。
2. 同一数据的回归树完全拟合训练目标。
3. 不产生 overflow warning、空节点或递归溢出。
4. 普通数据全量测试保持通过。

## Review 检查点

1. 回退右端点时 `< threshold` 是否保证左右均非空。
2. 是否仍有直接 `(a+b)/2` 阈值计算。
3. 极大异号浮点值是否得到有限中点。
