# PLAN-003 实施结果：修复回归树特征重要性

## 实施内容

1. 所有回归树节点保存真实 `n_samples` 和 `squared_error`。
2. 特征重要性根据父节点 SSE 减去左右子节点 SSE 计算。
3. `weighted=True` 作为默认标准行为，累计样本加权方差下降。
4. `weighted=False` 保留局部方差下降模式。
5. 删除通过叶均值重建节点目标值的错误逻辑。
6. 无分裂树的重要性归一化返回全零数组。
7. 剪枝生成的叶节点补齐训练统计量。

## Review 结果

1. 每个叶节点创建路径都保存了样本数和 SSE。
2. 每个内部节点保存当前节点原始目标值计算的 SSE。
3. 加权重要性等价于标准 CART 的节点 SSE 减少量。
4. 固定反例中主特征恢复为重要性第一名。
5. 与参考实现的细微差异来自后续等价分裂选择，不影响计算公式和主特征排序。
6. 未发现需要追加修复的问题。
