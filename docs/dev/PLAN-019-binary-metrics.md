# PLAN-019：修复二分类指标标签与概率语义

## 问题

precision、recall 和 F1 将正类 `1`、负类 `0` 写死。标签为 `{1,2}` 时假阳性不会计入，
字符串标签只能返回零。`log_loss` 直接对原标签做算术，非 `0/1` 标签产生无意义结果，
NaN 或越界概率也没有明确拒绝。

## 目标

1. precision、recall、F1 支持任意 `pos_label`。
2. 默认 `pos_label=1` 保持现有 `0/1` API。
3. 所有非正类标签按 one-vs-rest 负类处理。
4. `log_loss` 支持任意二分类标签和 `pos_label`。
5. `log_loss` 拒绝超过两类、正类不存在、NaN 和越界概率。
6. 合法概率仍进行数值裁剪避免 `log(0)`。

## 实施步骤

1. 为 precision、recall、F1 增加 `pos_label` 参数。
2. 按是否等于 `pos_label` 计算 TP、FP 和 FN。
3. 为 `log_loss` 增加 `pos_label` 参数并编码真实标签。
4. 校验类别数、正类存在性和概率范围。
5. 增加字符串标签、`{1,2}` 标签和非法概率测试。

## 验证

1. 字符串正类指标得到正确 precision、recall 和 F1。
2. `{1,2}` 默认正类 1 时正确计入标签 2 的假阳性。
3. 任意二分类标签对数损失与手工公式一致。
4. 多类别、NaN 和越界概率明确失败。
5. 运行指标测试和全量测试。

## Review 检查点

1. 默认 `0/1` 结果是否保持不变。
2. FP/FN 是否使用 one-vs-rest 定义。
3. 概率是否在校验后才裁剪。
