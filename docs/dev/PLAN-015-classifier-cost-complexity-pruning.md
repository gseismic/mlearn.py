# PLAN-015：修复分类树代价复杂度剪枝

## 问题

分类树剪枝仍使用未归一化的 `Gini * 节点样本数` 与单个 `ccp_alpha` 比较，并且只在
两个直接子节点都是叶子时考虑剪枝。该实现与标准代价复杂度目标不一致，较大 alpha 也
可能无法剪掉应当替换的子树。

## 目标

1. 使用全局样本加权 Gini 风险。
2. 复杂度使用叶节点数量。
3. 任意深度子树都可以与当前节点单叶比较。
4. 与标准 CART 在明确剪枝阈值下得到一致节点数。
5. 剪枝叶节点保留类别计数和样本数。

## 实施步骤

1. 在训练时保存根样本数。
2. 递归剪枝左右子树。
3. 汇总子树所有叶节点的 `n_samples * Gini` 和叶节点数。
4. 比较：
   - 子树代价：`叶风险和 / 根样本数 + alpha * 叶数`
   - 单叶代价：`当前节点风险 / 根样本数 + alpha`
5. 单叶代价不高于子树代价时使用统一叶节点构造器替换。
6. 增加与 scikit-learn 阈值一致性测试。

## 验证

1. 完全可分平衡数据在 `alpha < 0.5` 时保留分裂。
2. 同一数据在 `alpha >= 0.5` 时剪为单叶。
3. 剪枝后的预测和特征重要性均有效。
4. 运行分类树和全量测试。

## Review 检查点

1. 叶风险是否按根样本数统一归一化。
2. 复杂度是否只计叶节点。
3. 是否移除仅处理直接双叶子的限制。
