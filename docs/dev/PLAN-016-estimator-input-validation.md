# PLAN-016：统一树与集成模型输入校验

## 问题

树和集成模型各自直接使用输入形状。列向量回归目标会在 GBDT 中产生二维残差并广播失败，
回归树不支持一维单样本预测；空数据、样本数不一致和特征数不一致通常落到底层代码后才以
`IndexError` 或警告失败。

## 目标

1. 训练特征统一为非空二维有限实数矩阵。
2. 目标支持一维或单列二维输入，并统一为一维。
3. 回归目标必须是有限实数。
4. 训练前检查 X/y 样本数一致。
5. 预测支持一维单样本，并检查训练特征数。
6. 未训练模型预测时给出明确错误。

## 实施步骤

1. 新增共享 `validate_X`、`validate_y` 和 `validate_X_y`。
2. 分类树和回归树在 `fit/predict` 使用共享校验。
3. 两种随机森林在 `fit/predict` 使用共享校验。
4. 两种 GBDT 在 `fit/predict` 使用共享校验。
5. GBDT 回归训练状态统一使用浮点一维数组。
6. 增加列向量目标、单样本预测、空输入、样本不匹配和特征不匹配测试。

## 验证

1. GBDT 回归接受 `(n,1)` 目标并返回 `(n,)` 预测。
2. 回归树一维单样本预测返回 `(1,)`。
3. 所有估计器对空输入和样本数不一致给出 `ValueError`。
4. 预测特征数不一致给出 `ValueError`。
5. 运行目标测试和全量测试。

## Review 检查点

1. 分类目标是否仍允许字符串标签。
2. 回归目标是否不会保留二维形状。
3. bootstrap 前是否已完成样本数检查。
4. 预测是否在遍历树前检查拟合状态。
