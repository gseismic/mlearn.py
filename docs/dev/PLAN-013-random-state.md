# PLAN-013：隔离模型随机状态

## 问题

随机森林分类器在 `fit` 中调用全局 `np.random.seed`，会重置调用方随机序列。bootstrap
采样和决策树特征抽样都依赖全局 NumPy RNG；回归森林没有 `random_state`，无法稳定复现。

## 目标

1. 模型训练不读取或修改全局 NumPy 随机状态。
2. 相同 `random_state` 产生可复现模型。
3. 森林中的各棵树使用独立但可复现的子种子。
4. 回归森林支持 `random_state`。
5. 直接使用决策树时也可控制随机特征抽样。

## 实施步骤

1. 分类树和回归树增加 `random_state` 参数及私有 `Generator`。
2. 每次树训练时重新创建私有生成器。
3. 特征子集抽样改用私有生成器。
4. 两种随机森林使用本地生成器执行 bootstrap。
5. 为每棵子树从森林生成器派生独立整数种子。
6. 增加全局随机序列不变和模型可复现测试。

## 验证

1. 训练前后全局 `np.random` 后续输出保持不变。
2. 相同种子的两个分类森林预测一致。
3. 相同种子的两个回归森林预测一致。
4. 不同树获得不同子种子。
5. 运行树、森林和全量测试。

## Review 检查点

1. 仓库训练代码是否仍调用 `np.random.seed`。
2. bootstrap 和特征抽样是否均使用私有生成器。
3. 重复 `fit` 是否从配置种子重新开始。
