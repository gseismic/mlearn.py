# PLAN-002：分类树处理无有效分裂与零收益分裂

## 问题

当特征全部为常量时，`_best_split` 返回 `(None, None)`，`_grow_tree` 仍使用空阈值
比较数据，导致异常。当前逻辑还拒绝不纯度与父节点相同的合法分裂，使 XOR 数据无法继续
生长到后续可分节点。

## 目标

1. 没有合法阈值时生成多数类叶节点，不再异常。
2. 允许不纯度下降为零的合法分裂，以支持后续层级产生收益。
3. 无分裂树的特征重要性返回全零，而不是 `NaN`。
4. 保持已有正收益分裂行为。

## 实施步骤

1. 提取 `_make_leaf`，统一构造分类叶节点。
2. `_grow_tree` 检查最佳特征和阈值是否存在，不存在时返回叶节点。
3. `_best_split` 记录第一个合法候选，并继续选择更低基尼系数的候选。
4. 特征重要性归一化前检查总量是否为零。
5. 增加常量特征和 XOR 数据测试。

## 验证

1. 常量特征、混合标签训练成功并返回多数类。
2. 深度为 2 的 XOR 数据能够完全拟合。
3. 无分裂树特征重要性为有限的零数组。
4. 运行目标测试和全量测试。

## Review 检查点

1. 左右子节点是否仍保证非空。
2. 零收益分裂是否只发生在存在不同相邻特征值时。
3. 叶节点元数据是否与原停止条件保持一致。
