# PLAN-007：修复回归树代价复杂度剪枝

## 问题

当前剪枝条件比较子树平均 MSE 与单叶平均 MSE，并给子树误差加
`ccp_alpha * 全部节点数`。该目标不是标准代价复杂度目标，误差项与复杂度项的比较方式也
不一致，可能过早剪掉训练误差显著更低的子树。

## 目标

1. 使用可加的叶节点误差作为子树经验风险。
2. 复杂度只计算叶节点数量。
3. `ccp_alpha` 与全局平均平方误差使用一致尺度。
4. 剪枝后节点保留完整训练统计量。

## 实施步骤

1. 递归剪枝左右子树。
2. 计算当前子树所有叶节点 SSE 之和和叶节点数量。
3. 使用 `SSE / 根样本数 + ccp_alpha * 叶节点数` 计算子树代价。
4. 使用当前节点 SSE 构造单叶代价并比较。
5. 增加低 alpha 保留有效分裂、高 alpha 执行剪枝的边界测试。

## 验证

1. 训练误差为零、单叶 MSE 为 25 的树在 `ccp_alpha=10` 时保留。
2. 同一树在 `ccp_alpha=30` 时剪为单叶。
3. 剪枝后预测、节点数和特征重要性均有效。
4. 运行目标测试和全量测试。

## Review 检查点

1. 子树误差是否为所有叶节点 SSE 的和。
2. 复杂度是否只使用叶节点数量。
3. 局部剪枝比较是否使用统一的根样本数归一化。
